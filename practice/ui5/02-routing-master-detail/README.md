# 02. Routing · Master-Detail

고객 → 구매내역 → 구매 상세로 이어지는 화면 이동을 연습했습니다.

| 파일 | 내용 |
|---|---|
| `List` | 고객 검색 · 초기화, 고객 선택 → 구매내역, 정렬, 팝업, 한/영 전환 |
| `Detail` | `detail/{customerIndex}/{purchaseIndex}` 파라미터 2개 라우팅, 저장, 뒤로가기 |
| `GridList` | 같은 데이터를 다른 레이아웃으로 표시, Filter · Sorter |
| `Basic` | 계산기 · 구구단 · 별찍기 · 회원 검색 · 등록 |
| `i18n_ko.properties` | 한국어 리소스 |
