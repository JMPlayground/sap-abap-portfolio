# 01. UI5 기초 컨트롤

View마다 컨트롤을 하나씩 붙여 보며 바인딩 · 이벤트 · 팝업을 연습했습니다.

| 파일 | 내용 |
|---|---|
| `View1` | JSON 모델 조회 · 등록 · 수정, 검색 |
| `View2` | `sap.ui.table.Table`, 콤보박스 선택에 따른 필터, 행 선택 |
| `View3` | 등록 폼, Fragment 팝업 |
| `View4` | Filter · Sorter(이름순 · 나이순), formatter(전화번호 · 날짜) |
| `Detail` | SimpleForm 상세 화면, 저장 |
| `*.fragment.xml` | 팝업 · 추가 정보 입력용 Fragment 4개 |
